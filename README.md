# edgardjcuadra.github.io

Personal portfolio built with Jekyll and served by GitHub Pages. No theme or JavaScript frameworks; styles live in `assets/css/site.css`.

To add a project, append an entry to `_data/projects.yml` (title, category, url, image, description, tags, links). The index page renders it automatically via `_includes/project.html`.

Long-form write-ups are Markdown pages using `layout: wide_default`. Preview locally with `bundle exec jekyll serve` or `jekyll serve`.
